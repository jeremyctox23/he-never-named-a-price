# He Never Named a Price

A free, interactive masterclass for fractional chiefs: anyone who brings a skill into a company and makes it grow.

- **Play** a real 60-minute partnership call, one decision at a time, with video of each move.
- **Study** the twelve moves and why each one works.
- **Build** your own multi-year deal: qualify it, model it, copy a one-page outline and a call plan.
- **Drill** the lines.

The call is Lior Weinstein's, used with his permission. The client is not named or shown.

This is a teaching tool. It is not legal, tax or financial advice.

## How this site is hosted

It is a static site served by GitHub Pages from the `main` branch: `index.html` plus the `clips/` folder. There is nothing to build.
